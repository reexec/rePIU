## rePIU v0.0.228

이전 릴리스 **v0.0.227** 이후의 변경입니다(issue #76 후속). **브라우저 페이지에서 OSD(Tab)가 열리고 마우스로 조작됩니다.** 배포
빌드(Windows·Linux)의 동작은 바뀌지 않습니다.

### 반영된 issue

| issue | 내용 | PR |
|---|---|---|
| [#76](https://github.com/reexec/rePIU/issues/76) | 브라우저 페이지의 입력: 후속으로 OSD와 마우스 | [#85](https://github.com/reexec/rePIU/pull/85) |

### 바뀐 것

* **OSD:** 브라우저에서 Tab(패드는 LT+RT+Y)으로 OSD가 열립니다. 지금까지는 OSD가 SDL 창을 요구해 브라우저에서 아예 만들어지지
  않았습니다.
* **마우스:** 캔버스 위의 마우스(이동·클릭·휠)가 OSD에 전달됩니다.
* **시작:** 브라우저가 소리를 허락하지 않아도 게임이 시작됩니다(소리는 다음 클릭이나 키 입력 때 다시 켜 봄).

### 확인한 것

| 구성 | 확인 |
|---|---|
| 브라우저(headless Chrome) | Tab으로 OSD 표시, OSD의 "Keep aspect ratio" 클릭 반영, 자동 재생 허용 없이 게임 시작 |
| Win32 Debug·Release·`emulated`, Linux x64·i386, 웹 | 빌드, core probe |

### 알려진 것

* OSD의 전체 화면 항목은 브라우저에서 동작하지 않습니다. 화면 셰이더는 브라우저에서 아직 시험하지 않았습니다.
* 사용자 브라우저에서의 OSD·마우스·패드 확인이 남았습니다.

## rePIU v0.0.228

Changes since **v0.0.227** (a follow-up to issue #76). **The OSD (Tab) opens on the browser page and takes the mouse.**
Release builds (Windows, Linux) behave as before.

### Issues addressed

| issue | Summary | PR |
|---|---|---|
| [#76](https://github.com/reexec/rePIU/issues/76) | Input in the browser page: the OSD and the mouse, as a follow-up | [#85](https://github.com/reexec/rePIU/pull/85) |

### Changed

* **OSD:** Tab (LT+RT+Y on a pad) opens the OSD in the browser. Until now the OSD required an SDL window and was never
  made in the browser.
* **Mouse:** the mouse over the canvas (moves, clicks, the wheel) reaches the OSD.
* **Start:** the game starts even when the browser holds sound back (the next click or key tries the sound again).

### Checked

| Configuration | Check |
|---|---|
| Browser (headless Chrome) | the OSD shows on Tab, a click on the OSD's "Keep aspect ratio" takes effect, the game starts without autoplay permission |
| Win32 Debug, Release and `emulated`, Linux x64 and i386, web | build, core probe |

### Known

* The OSD's fullscreen option does nothing in the browser. The screen shaders are untested in the browser.
* Checking the OSD, the mouse and pads in the user's browser is still to do.

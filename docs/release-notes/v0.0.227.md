## rePIU v0.0.227

이전 릴리스 **v0.0.226** 이후의 변경입니다(issue #81). **브라우저 페이지에서 소리가 나옵니다.** 배포 빌드(Windows·Linux)의 소리는
바뀌지 않습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#81](https://github.com/reexec/rePIU/issues/81) | 브라우저 페이지의 소리: 세 오디오 출력을 섞어 AudioWorklet으로 | `fca6380` |

### 바뀐 것

* **소리:** 효과음(YMZ280B), 음악(PIU10 MP3), CD 오디오를 엔진이 섞어 페이지의 AudioWorklet으로 보냅니다. Start를 누를 때 소리가
  켜집니다.
* **상태 줄:** 페이지에 `Sound: … ms buffered, peak …, … underruns`가 보입니다.
* 네이티브는 지금처럼 SDL 오디오 장치로 냅니다(스트림을 여는 코드만 한 곳으로 모음).

### 확인한 것

| 구성 | 확인 |
|---|---|
| 브라우저 | 사용자가 소리 확인. headless Chrome 5분 동안 버퍼 약 130 ms, 끊김 0회 |
| Win32 | MP3 통계가 이전과 같음, core probe |
| Linux x64·i386, 웹 Node | 빌드, core probe |
| CI | Win32 Debug 빌드와 probe |

### 알려진 것

* 브라우저의 게임이 아직 실시간보다 느려 음악이 끊길 수 있습니다.
* 브라우저에서 OSD(Tab)가 열리지 않습니다(다음 작업).

## rePIU v0.0.227

Changes since **v0.0.226** (issue #81). **Sound plays on the browser page.** Release builds (Windows, Linux) sound as
before.

### Resolved issues

| issue | Summary | Commit |
|---|---|---|
| [#81](https://github.com/reexec/rePIU/issues/81) | Sound in the browser page: the three audio outputs mixed into an AudioWorklet | `fca6380` |

### Changed

* **Sound:** the engine mixes the effects (YMZ280B), the music (PIU10 MP3) and CD audio and sends them to an AudioWorklet
  on the page. Sound starts when Start is pressed.
* **State line:** the page shows `Sound: … ms buffered, peak …, … underruns`.
* Natively the sound still goes through SDL's audio device (only the code that opens the streams moved to one place).

### Checked

| Configuration | Check |
|---|---|
| Browser | sound confirmed by the user; over 5 minutes in headless Chrome about 130 ms buffered, no underrun |
| Win32 | MP3 statistics as before, core probe |
| Linux x64 and i386, web under Node | build, core probe |
| CI | Win32 Debug build and probes |

### Known

* The game in the browser still runs slower than real time, so the music may break up.
* The OSD (Tab) does not open in the browser (next).

## rePIU v0.0.226

이전 릴리스 **v0.0.225** 이후의 변경입니다(issue #79). **웹 빌드의 게임 코드가 rex86의 wasm 번역으로 돕니다.** 배포 빌드(Windows·Linux)의
동작은 바뀌지 않습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#79](https://github.com/reexec/rePIU/issues/79) | 웹 빌드의 게스트를 rex86의 wasm 번역으로 돌리고 측정 | `7539353` |

### 바뀐 것

**웹 빌드가 약 3.5배 빨라졌습니다.** 지금까지 웹 빌드는 CPU 에뮬레이터 rex86의 인터프리터만 썼습니다. 이제 자주 도는 게임 코드를
WebAssembly로 번역해 실행합니다.

* **결과(pumpitea, Node, 60초):** 약 6 → 21 MIPS, 부팅이 끝나 입력을 읽기 시작할 때까지 56초 → 18초. 실행 단계의 약 94%가
  번역된 코드 안에서 돕니다.
* **같게 도는지:** 번역을 끄고 켠 실행의 HLE 경계 기록이 첫 벽시계 의존까지 바이트 단위로 같습니다.
* **설정:** `REPIU_REX86_TRANSLATION=off`로 끌 수 있습니다(기본 `wasm`).
* 브라우저에서 게임이 도는 것을 사용자가 확인했습니다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| 웹(Node) | core probe, pumpitea 번역 끄고 켠 경계 기록 대조, 처리량 측정 |
| 브라우저 | 사용자 실행 |
| Win32 `direct`·`emulated` | core probe, pumpitea 실행 |
| CI | Win32 Debug 빌드와 probe |

### 알려진 것

* 소리가 아직 없습니다(다음 작업, [#81](https://github.com/reexec/rePIU/issues/81)).
* 60fps까지는 아직 약 3배 남짓 모자랍니다(추정).

## rePIU v0.0.226

Changes since **v0.0.225** (issue #79). **The web build's game code runs on rex86's wasm translation.** Release builds
(Windows, Linux) behave as before.

### Resolved issues

| issue | Summary | Commit |
|---|---|---|
| [#79](https://github.com/reexec/rePIU/issues/79) | Run the web build's guest on rex86's wasm translation, and measure it | `7539353` |

### Changed

**The web build is about 3.5 times faster.** Until now it ran only the rex86 CPU emulator's interpreter; frequently run
game code is now translated to WebAssembly and run.

* **Result (pumpitea, Node, 60 s):** about 6 → 21 MIPS; from start to the game reading input, 56 s → 18 s. About 94% of
  the steps run inside translated code.
* **Same behaviour:** the HLE boundary traces with translation off and on match byte for byte up to the first wall-clock
  dependence.
* **Setting:** `REPIU_REX86_TRANSLATION=off` turns it off (the default is `wasm`).
* The user confirmed the game runs in the browser.

### Checked

| Configuration | Check |
|---|---|
| Web (Node) | core probe, pumpitea boundary traces with translation off and on, throughput |
| Browser | run by the user |
| Win32 `direct` and `emulated` | core probe, pumpitea run |
| CI | Win32 Debug build and probes |

### Known

* No sound yet (next, [#81](https://github.com/reexec/rePIU/issues/81)).
* Still a little over 3 times short of 60 fps (estimated).
